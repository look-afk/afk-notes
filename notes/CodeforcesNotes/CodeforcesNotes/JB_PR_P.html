Так для того что бы решить эту задачу нам не достаточно только знания префикс сумма.
Давайте немного усложним задачу. Пусть для каждого l,r мы будем вычислять 

a[l] + 2a[l+1] + 3a[l+2]... (r-l+1)a[r]

Для этого мы применим хитрый ход, будем хранить в другом массиве веса первого.
Идея S[i] = a[1] + a[2] + a[3] ... + a[i] W[i] = 1a[1] + 2a[2] + ... i*a[i]
Тогда для l,r

Вот как можно это реализовать 

n,k = map(int,input().split())
s = list(map(int,input().split()))

dp = [0] * (n+1)
pr = [0] * (n+1)

for i in range(1,n+1):
    dp[i] = dp[i-1] + s[i-1]
for i in range(1,n+1):
    pr[i] = pr[i-1] + s[i-1] * i
for i in range(k):
	l,r = map(int,input().split())
	ans = pr[r] - pr[l-1] - (l - 1) * (dp[r] - dp[l-1])
	print(ans)

Давайте рассмотрим этот код и поймем что он вообще делает. В начале у нас идет инициализация, дальше мы создаем два цикла, в первом мы создаем префикс сумм массива s, а во втором мы создаем веса массива s (где pr[i] = pr[i-1] + a[i-1] * i => pr[i] = прошлый pr[i] складываем с a[i] умноженное на i ). В конце мы делаем какую то магию но что это такое вообще?. Давайте рассмотрим этот код поближе 

ans = pr[r] - pr[l-1] - (l - 1) * (dp[r] - dp[l-1])

Давайте приведем пример
Пусть массив a = [3, 2, 6, 1, 5]
Тогда dp[i] = a[1] + a[2] + ... + a[i] (обычный прей сумм)
И pr[i] = 1 a[1] + 2 a[2] + ... + i* a[i] (Преф сумм только весса массива a)

В результате для этого массива a мы получим 

dp = [0, 3, 5, 11, 12, 17]
pr = [0, 3, 7, 25, 29, 54]

1 Первая часть pr[r] - pr[l-1]
Это взвешенная сумма на отрезке от l до r но с неправильными весами например для запроса pr[4] - pr[1] = 29 - 3 = 26
Что же там внутри ?

2*a2 + 3*a3 + 4*a4
= 2*2 + 3*6 + 4*1
= 26

А нам нужно 

1*a2 + 2*a3 + 3*a4
= 1*2 + 2*6 + 3*1
= 17

Ошибка в том что каждый вес больше на ровно l - 1
При l = 2, нужные веса это 1 2 3 а веса из pr = 2 3 4
2 Вторая часть dp[r] - dp[l-1]
dp[4] - dp[1] = 12 - 3 = 9 (это обычная сумма элементов на отрезке от l до r)
То есть типа a2 + a3 + a4 = 2 + 6 + 1 = 9

3 Собираем нужную формулу
лишнее = (l - 1) (a_l + a_{l+1} + ... + a_r) (а это как раз (l - 1) (dp[r] - dp[l-1]))
Поэтому ans = pr[r] - pr[l-1] - (l - 1) * (dp[r] - dp[l-1])

(r - l + 1) a[l] + (r - l) a[l+1] + ... + 1 * a[r]
